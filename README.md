## 🚀 GitHub'a Gönderme ve Vercel'e Dağıtım (Deploy)

### 1. GitHub Reposuna Pushlamak:

Terminalde aşağıdaki komutları çalıştırarak projenizi GitHub hesabınıza aktarabilirsiniz:

```bash
git init
git add .
git commit -m "feat: Doğuş Mercedes Samsun web sitesi"
git branch -M main
git remote add origin https://github.com/CoskunerBerke/<REPO_ADI>.git
git push -u origin main
```

*(Not: `<REPO_ADI>` yerine GitHub'da açacağınız yeni repository adını yazınız, örneğin `dogus-mercedes-samsun`)*

---

### 2. Vercel ile 1 Tıkla Yayınlama:

1. [vercel.com](https://vercel.com) adresine gidin ve GitHub hesabınızla giriş yapın.
2. **"Add New Project"** butonuna tıklayın.
3. GitHub reponuzu seçin (`CoskunerBerke/dogus-mercedes-samsun`).
4. Framework Preset olarak **Vite** otomatik algılanacaktır.
5. **"Deploy"** butonuna basın. Projeniz 30 saniye içinde dünya çapında canlıya geçecektir!
